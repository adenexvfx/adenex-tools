PyToolkit — Changelog

v2.2 UE 5.8 2026-08-13
  • AddedUser-facing error dialogs for common subprocess launch failures: file not found, path not found, access denied, invalid executable, and architecture mismatch (WinError 2, 3, 5, 193, 216). Previously these were silently reported as unhandled exceptions.
v2.1 UE 5.8 2026-07-30
  • AddedShared Slate style system (PyToolkitStyle) for consistent UI across PyToolkit-based panels.
  • AddedBundled Python libraries: adenexlib_core for shared Unreal Editor helpers and diagnostics, and datamodel_core for Valve DMX data model parsing and serialization.
  • AddedAdditional reusable Slate widgets: PyComboBox, PyGradientCard, and PySectionLabel.
  • ChangedUpdate checker now uses a string slug to read release metadata from the adenex-tools repository on GitHub Pages; WordPress is no longer queried.
v2.0 UE 5.8 2026-06-29
  • AddedEditor toolbar button — PyToolkit icon registered in the main UE toolbar via UToolMenus, opens the panel instantly.
  • AddedCustom Slate widget library: PyButton, PyIconButton, PyTabButton, PyWarningMessage — available for plugins that build UI on top of PyToolkit.
  • AddedUnified style system (PyToolkitStyle) for consistent look-and-feel across PyToolkit-based panels.
  • AddedUpdate checker — on startup, fetches version JSON from GitHub Pages and shows an in-editor notification with Open Page and Dismiss buttons when a newer version is available.
  • AddedCheckPluginVersion and CheckWidgetVersion as separate BlueprintCallable functions.
  • AddedGetAssetDependencies — query all assets a given asset depends on, with Hard / Soft / Manage filter.
  • AddedGetAssetReferencers — find all assets that reference a target asset.
  • AddedFixupRedirectors — batch fix asset redirectors in a given content path.
  • AddedAddParticleActivateKey and AddParticleDeactivateKey — separate Niagara activation / deactivation key insertion into Sequencer tracks.
  • ChangedAddParticleTriggerKey and AddParticleKey now accept SubFrame and TimeUnit parameters for sub-frame precision.
  • ChangedModule loading phase changed to PostEngineInit.
  • ChangedUpdate checker uses a string slug instead of a numeric WordPressPostId to identify plugins.
v1.9 UE 5.6 UE 5.7 UE 5.8
  • AddedBlueprintVarMetaCustomization — extends the metadata customization system to Blueprint-native variables, enabling metadata editing on Blueprint-defined pins in the Details panel.
  • FixedStability improvements and edge-case fixes in AnyMetaCustomization and EditConditionEvaluator.
  • ChangedModule type changed to UncookedOnly.
v1.8 UE 5.6 UE 5.7
  • AddedAnyMetaCustomization — set arbitrary metadata key-value pairs on UPROPERTY fields from Python or Blueprint.
  • AddedAnyMetaSettings — configuration object for AnyMetaCustomization behavior.
  • AddedEditConditionEvaluator — evaluates EditCondition expressions at runtime, enabling dynamic property visibility checks from Python.
  • AddedSetAnimationSectionWeight — set the weight of an animation section in Sequencer.
  • AddedIsStaticSwitchOverridden, GetOverriddenStaticSwitches — inspect which static switch parameters are overridden in a material instance.
  • AddedResetStaticSwitchToDefault, ResetAllOverriddenStaticSwitches — revert material instance static switch overrides.
  • AddedAdditional skeleton bone query functions: GetSkeletonBoneIndex, GetSkeletonBoneChildren, BoneExistInSkeletalMesh, GetAllSkeletalMeshBones, GetAllSkeletonBones.
v1.7 UE 5.6
  • AddedTimingBPLibrary — performance profiling API: StartTimedSection, FinishTimedSection, LogTimedStats, ResetTimedStats. Supports named nested sections and aggregated reporting to the Output Log.
  • AddedVarByNameLite — lightweight variable access by name without full reflection traversal.
v1.6 UE 5.5 UE 5.6
  • AddedNotification system redesign — new EState and ESeverity enums; ShowNotification accepts severity level and auto-dismiss timeout.
  • AddedMessage log system: RegisterWidgetMessageLog and related functions for routing Python output to the UE Message Log window.
  • AddedBlueprint variable editor functions — query and modify Blueprint variable pin types and metadata from Python.
  • AddedMaterial static switch functions: get / set / reset static switch parameter values on material instances.
  • RemovedPyCommandList system (PyCommandList.cpp / .h).
  • ChangedModule type changed to Developer, loading phase to Default.
v1.5 UE 5.4
  • AddedNiagara / Particle key API: AddParticleTriggerKey, AddParticleKey — insert Niagara system keys into Sequencer tracks.
  • AddedTexture utilities: TextureHasAlphaChannel, GetTextureSize.
  • AddedSlow task API: BeginSlowTask, EndSlowTask, StatusUpdate — show a progress bar in the editor during long operations.
  • ChangedPlugin whitelisted to Win64 platform only.
  • ChangedHeader includes cleaned up and updated for UE 5.4 API changes.
v1.1 – v1.4 UE 5.0 UE 5.1 UE 5.2 UE 5.3
  • ChangedIncremental UE5 compatibility updates — header include paths adjusted per engine release.
  • FixedCompile fixes for deprecated or renamed engine symbols in UE 5.1 – 5.3.
v1.0 UE 4.27
  • ChangedFork of FXTD-ODYSSEY/Unreal-PyToolkit. Changes relative to the original:
  • AddedSetMaterialInstanceComponentMaskParameter — set RGBA channel mask and override flag on a material instance static parameter.
  • ChangedSetMaterialInstanceStaticSwitchParameterValue — added bOverride parameter; implementation rewritten to use GetAllStaticSwitchParameterInfo for correct lookup.
  • ChangedMaterial function category renamed from RedArtToolkit|Material to PyToolkit|Material.
  • FixedGetCurrentContentPath — was commented out in the original; re-enabled.
