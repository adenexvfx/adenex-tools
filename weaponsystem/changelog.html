Weapon System — Changelog

v1.61
  • FixedWeaponSystem Niagara: Changed the muzzle flash spawn pooling method from Auto Release to None. Fixes an issue where the muzzle flash sometimes wouldn't spawn (UE 5.8 bug).
v1.6
  • AddedAdded support for AFX Live Link plugin.
  • ChangedThe ricochet and penetration logic has been rewritten.
  • ChangedThe bool Is 3rd Person has been removed and replaced with the Mode dropdown (First Person / 3rd Person / AFX Plugin).
  • ChangedThe tracer and shell casing logic has been reworked.
  • ChangedTracers Every Shot replaced with Tracers Every N Shots — set the exact number of shots after which a tracer appears.
  • FixedFixed a bug where the tracer would fly directly out of the camera in first-person mode.
v1.5
  • AddedNiagara version (particles + bake widget for Niagara included).
  • AddedTracing offset — allows moving the target tracing point, useful for 3rd-person weapons.
  • ChangedTracing logic moved into its own group.
v1.4
  • AddedWallbang support.
  • AddedBlood decal spawns on player models when hit by a shot.
  • AddedEach wall in the wallbang loop now spawns a particle effect, plays an impact sound, and generates an impact decal.
  • AddedInit System, Reset Bones, Reset Spray, and Reset System buttons added directly to the Setup panel.
  • AddedTooltips added to all variables (displayed on mouse hover).
  • AddedSocket/bone name fields exposed directly in the Blueprint for manual override.
  • ChangedRemoved the requirement to use GetCurrentTime node in Blueprint Director to initialize the system.
  • ChangedReworked the baking widget — consumes fewer resources and runs significantly faster.
  • ChangedRenamed variables for improved clarity.
  • ChangedAdjusted shell casing behavior.
  • ChangedUpdated the DemoLevel map — added WeaponSystem Blueprint and sequence with wallbang logic for demonstration.
