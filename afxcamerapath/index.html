Adenex / AFXCameraPath
AFXCameraPath
Unreal Engine Plugin v1.4
A free community plugin for Unreal Engine 5 that adds an HLAE-style camera path workflow inside the editor. Create camera paths from keyframes, preview them live with a Cine Camera, import/export HLAE .bvh / .cam files, and bake the result to Sequencer.
Бесплатный плагин для Unreal Engine 5 с HLAE-style рабочим процессом путей камеры прямо в редакторе. Создавайте пути из кейфреймов, просматривайте их в реальном времени через Cine Camera, импортируйте и экспортируйте файлы HLAE .bvh / .cam, а также запекайте результат в Sequencer.

Также доступен режим постоянной скорости движения.

  1. Open the plugin tool window from the editor toolbar.
  2. Create an AFX Camera Path Actor in the level.
  3. Select or create your Cine Camera Actor.
  4. Create keys with Add From View — captures the current viewport or piloted camera.
  5. Use Update From Current View to refresh a selected key from the current shot.
  6. Use Snap Camera To Key to jump the active camera or editor view to a selected key.
  7. Adjust keyframe position, rotation and lens parameters directly in the viewport with the transform gizmo.
  8. Preview the path live in the viewport.
  9. Bake to Sequencer or export to .bvh / .cam.

  4. Создавайте кейфреймы через Add From View — захватывает текущий вьюпорт или piloted-камеру.
  5. Используйте Update From Current View, чтобы обновить выбранный кейфрейм из текущего положения камеры.
  6. Используйте Snap Camera To Key, чтобы перевести активную камеру или вьюпорт к выбранному кейфрейму.
  7. Редактируйте позицию, ротацию и параметры объектива прямо во вьюпорте с помощью transform gizmo.
  8. Просматривайте путь в реальном времени во вьюпорте.
  9. Запекайте в Sequencer или экспортируйте в .bvh / .cam.
  1. Download and extract the plugin archive.
  2. Place the AFXCameraPath folder into the Plugins folder of your UE5 project (create it if it doesn't exist): YourProject/Plugins/AFXCameraPath.
  3. Open the project in Unreal Engine. The plugin will compile automatically on first launch.
  4. Enable the plugin in Edit > Plugins, then restart the engine.
  5. The AFXCameraPath panel will appear in the editor toolbar.
