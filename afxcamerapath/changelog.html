AFXCameraPath — Changelog

v1.4 2026-05-10
  • AddedKeyframe label display mode: Off, Selected Only, All, and Every N — controlled per-component from the editor panel.
  • AddedLabel step control for Every N mode — draws label at index 0, N, 2N… plus always draws the selected key.
  • AddedAfter HLAE .bvh / .cam import, label mode auto-switches to Every N to keep dense imports readable.
  • AddedShift-click multi-select in the timeline — toggle individual keys into the selection set.
  • AddedGroup time drag — dragging any key in a multi-selection moves all selected keys by the same delta.
  • AddedNegative key time support — keys can now be placed before time 0 (useful for pre-roll). Timeline markers for negative-time keys pile at pixel 0; data is preserved.
  • ChangedPreview playhead clamp still enforces t ≥ 0; data times are unclamped.
v1.3
  • AddedBake to Sequencer now detects an already-open Level Sequence and bakes into it directly — no Save dialog shown.
  • AddedSelect Camera button in the active camera row — calls GEditor→SelectActor on the Cine Camera Actor.
  • ChangedPreview is now enabled by default when the panel opens.
  • ChangedSequencer time and plugin preview time now sync bidirectionally — scrubbing Sequencer moves the plugin playhead and vice versa, guarded against feedback loops.
  • ChangedDefault bake sequence asset name set to AFXCamera_Sequence.
  • ChangedKeyframe 20-second hard time cap removed — the spinner now uses a soft UI hint only.
  • ChangedTimeline always starts at 0 and has a minimum displayed duration of 5 seconds.
  • FixedKeyframe selection is now preserved after property edits (Focal Length, etc.) — previously any transaction cleared the selection. Selection is now tracked by stable FGuid, not array index.
  • FixedViewport transform gizmo is now restored after editing a Focal Length value in the details panel.
  • FixedSequencer bake absolute timing — the first baked key now maps to its correct Sequencer time instead of always landing on frame 0.
  • FixedCamera Cuts track now appears at the top of the Sequencer outliner (uses AddCameraCutTrack instead of the generic track array).
  • FixedRe-baking no longer accumulates stale Camera Cuts entries in the Sequencer track list.
  • FixedDuplicate camera and component bindings in Sequencer are now prevented on repeated bakes.
  • FixedTransform and Focal Length tracks are cleared before each bake instead of appending new keys on top of old ones.
  • FixedBuild error caused by a reference to the non-existent FOV field — replaced throughout with FocalLength.
v1.2 2026-05-02
  • FixedToolbar and Window menu registration rewritten using the UToolMenus API (PlayToolBar + Window menu). Resolves a crash on startup caused by the previous hook attaching to the wrong toolbar slot.
v1.1 2026-05-02
  • FixedToolbar hook corrected — was incorrectly attached to the Compile slot instead of Settings, preventing the panel button from appearing.
v1.0 2026-05-02
  • AddedInitial release.
  • AddedAFX Camera Path Actor — place in the level to author a camera path.
  • AddedPer-keyframe control: Position, Rotation, Focal Length, Focus Distance, Aperture.
  • AddedInteractive timeline with playhead scrubbing and keyframe diamonds.
  • AddedLive viewport preview driven by FTSTicker — animates the active Cine Camera Actor along the path.
  • AddedViewport drawing: spline curve, keyframe gizmos, camera frustum, direction arrows.
  • AddedBake to Sequencer — writes transform and focal length tracks at display rate with a Camera Cuts entry.
  • AddedHLAE .bvh and .cam import and export.
  • AddedPosition interpolation: Catmull-Rom (Uniform / Centripetal), Bezier, Hermite, Linear, B-Spline.
  • AddedRotation interpolation: Slerp, Slerp Smootherstep, Squad, Squad Safe, Quaternion Bezier, Quaternion Moving Average, Cubic + Smooth Roll, Swing-Twist Smooth, Look Ahead Along Path.
  • AddedTime easing: Linear, Ease In, Ease Out, Ease In-Out, Cinematic Ease.
  • AddedOptional constant-speed motion mode.
  • AddedDockable editor panel available under Window → Cinematics → AFX Camera Path.
